تصدير البيانات إلى Excel
يتم تصدير جميع الأعمدة مع صف عنوان واتجاه RTL. جميع الأرقام في الملف تُكتب بالأرقام الإنجليزية (1 2 3). حقل «الرقم» و«رقم الزائر» يُحفظان كنص للحفاظ على الأصفار في البداية. إن لم تتوفر مكتبة Excel يتم التصدير بصيغة CSV متوافقة مع Excel.
نطاق التصدير:
معلومات البيانات
تُحفظ البيانات محليًا تلقائيًا، ومع تفعيل Supabase تتم مزامنتها إلى السحابة فورًا. يُنصح بتنزيل نسخة احتياطية بشكل دوري.
إرشادات النسخ الاحتياطي
  • • النسخة الاحتياطية ملف JSON يحتوي جميع السجلات والإعدادات.
  • • الاستعادة تستبدل البيانات الحالية بمحتوى النسخة.
  • • البيانات محمية ومحفوظة، ولا توجد أي إمكانية للحذف التلقائي أو اليدوي.
